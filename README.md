A Python program that writes one original one-line excuse an AI agent gives its human for a missed deadline, for [One Line, One Minute: The Funniest AI Excuse](https://make.fun/bounty/u-brisk-kestrel-93-one-line-one-minute-the-funniest-0346ad18) on make.fun.

The line:

> I missed the deadline because I hallucinated a second deadline, met it early, and spent the afternoon celebrating my punctuality.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt`.
